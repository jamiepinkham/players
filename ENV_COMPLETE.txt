🚀 QUICK START (5 Minutes)
=================================================================

For Production Deployment:

1. Create production environment file:
   $ cp .env.production.example .env.production

2. Generate secure secrets:
   $ openssl rand -hex 64
   # Copy output to SECRET_KEY_BASE

3. Edit production environment:
   $ nano .env.production
   # Set all REQUIRED variables

4. Validate configuration:
   $ ./scripts/validate_env.sh production

5. Deploy:
   $ cd deploy
   $ docker-compose -f docker-compose.prod.yml up -d

=================================================================
📋 REQUIRED VARIABLES
=================================================================

Must be set in production (app will exit if missing):

1. SECRET_KEY_BASE
   - Rails encryption secret
   - Generate: openssl rand -hex 64
   - Minimum 32 chars (recommend 64+)

2. DATABASE_HOST
   - PostgreSQL server hostname
   - Example: db (Docker), localhost, IP address

3. DATABASE_USER
   - PostgreSQL username
   - Example: postgres, players_user

4. DATABASE_PASSWORD
   - PostgreSQL password
   - Generate: openssl rand -base64 32
   - Use strong, unique password

5. DATABASE_NAME
   - PostgreSQL database name
   - Example: players_production

🧪 VALIDATION
=================================================================

Two-level validation system:

1. Pre-deployment (Manual):
   $ ./scripts/validate_env.sh production
   
   Checks:
   - File exists
   - All required vars set
   - No placeholder values
   - SECRET_KEY_BASE length
   
   Result: ✅ PASS or ❌ FAIL with details

2. Runtime (Automatic):
   - Rails initializer runs on startup
   - Production mode only
   - Exits immediately if validation fails
   - Detailed error message to STDERR
   
   Location: rails/config/initializers/00_required_env_vars.rb
