# ✅ README.md
### 🚀 BMPL Development Environment

This repo provides a streamlined, Docker-based development setup for the BMPL Rails app — including environment bootstrapping, database seeding from a `.restore` dump, and a Foreman-powered dev workflow.

tl;dr: 
   - clone
   - run `bin/setup`
   - optionally, run `bin/restore`
   - run `bin/dev`
---

## 🧱 Requirements

- [Docker + Docker Compose](https://www.docker.com/products/docker-desktop)
- Ruby & Node.js are **not** required locally
- Optional: `tree`, `foreman`, and `pg_restore` (used inside the container)

 ### 📁 Project Structure
```
.
├── bin/                    # Local helper scripts
├── rails/                  # Rails app codebase
├── docker/                 # DB restore dumps, Postgres init
├── Dockerfile.web          # Rails app image
├── docker-compose.yml
```

---

## ⚙️ First-Time Setup

From the project root:

```
./bin/setup
```
This will:
* Ensure Docker is installed and running
* Create a .env file from .env.template if needed
* Start the database container
* Prepare the system for development

## 🐳 Running the App
`./bin/dev`

### 📘 What it does
This script starts the full application stack defined in docker-compose.yml using your local .env file for environment variables.

### ✅ Behavior
* Uses --env-file .env to load environment variables
* Starts all services in the foreground (Rails, DB, asset pipelines, etc.)
* Ensures logs are streamed and accessible directly in the terminal
### 🧠 Notes
* If .env doesn't exist, make sure to run `./bin/setup` first
* background `docker compose --env-file .env up -d`

### 🗃️ Restoring the Database from a Dump

To restore a .restore file located at docker/db/restore/latest.restore:

`./bin/restore`
This will:
* Wait for Postgres to be ready
* If the dump file exists:
   * Run rails db:create
   * Run pg_restore using PGPASSWORD from .env
   * Run rails db:migrate
If no dump is found:
* Run rails db:create db:migrate db:seed

### 🔐 Environment Variables

Defined in .env (autogenerated from .env.template):
```
DATABASE_USER=x
DATABASE_PASSWORD=y
DATABASE_NAME=z
DATABASE_HOST=a
RAILS_SECRET_KEY=123ChangeMe
RAILS_ENV=development
```

### 🧼 Cleaning Up

To reset the database completely:

```
docker compose down -v
./bin/restore
```

🧠 Tips

* `wait-for-it.sh` ensures the Rails server doesn’t start before Postgres is ready
* Database restore is fully automated and configurable via .env
* You can add custom dump files to docker/db/restore/ and update bin/restore to use them
