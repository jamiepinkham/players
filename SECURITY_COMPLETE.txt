🔒 HOST AUTHORIZATION
=================================================================

How It Works:
-------------
1. Rails checks Host header on every request
2. Compares against explicit allowlist
3. Rejects requests with invalid Host (403 Forbidden)
4. Prevents DNS rebinding attacks

Configuration:
--------------
# Primary hostname (required)
APP_HOST=players.billymartinplayersleague.com

# Additional hostnames (optional)
TRUSTED_HOSTS=www.players.billymartinplayersleague.com

Default Hostname:
-----------------
players.billymartinplayersleague.com

Rules:
------
✅ Explicit hostnames only
❌ NO wildcards (*.example.com)
✅ Subdomain.example.com is separate from example.com
❌ NO protocols (https://)
❌ NO ports (:443)

Allowed Hosts by Environment:
-----------------------------
Production:
  • Explicit list from APP_HOST + TRUSTED_HOSTS
  • NO wildcards
  • Fails on startup if wildcards detected

Development:
  • localhost, 127.0.0.1
  • *.local, *.localhost patterns
  • All IPv4 and IPv6 addresses

Test:
  • localhost, 127.0.0.1
  • example.com, www.example.com
  • test.host

🔐 HTTPS ENFORCEMENT
=================================================================

Status: ✅ ALWAYS ENABLED in production

Configuration:
--------------
File: rails/config/environments/production.rb
Setting: config.force_ssl = true

What It Does:
-------------
1. HTTP → HTTPS Redirect
   - All HTTP requests → 301 Redirect to HTTPS
   - Automatic and transparent

2. Secure Cookies
   - All cookies have Secure flag
   - Cookies only sent over HTTPS
   - Session cookies are secure

3. HSTS Header
   - Strict-Transport-Security header added
   - Tells browsers to always use HTTPS
   - Duration: 1 year (max-age=31536000)

4. Asset URLs
   - All assets served over HTTPS
   - CSS, JavaScript, images use HTTPS URLs

HSTS Header:
-----------
Strict-Transport-Security: max-age=31536000; includeSubDomains

Asset URLs:
-----------
✅ https://players.billymartinplayersleague.com/assets/application.js
❌ http://players.billymartinplayersleague.com/assets/application.js

🐛 TROUBLESHOOTING
=================================================================

Issue: "Blocked host" error in production
Fix:
  1. Add hostname to TRUSTED_HOSTS
  2. Restart application
  3. Check startup logs

Issue: Infinite redirect loop
Fix:
  1. Ensure proxy sets X-Forwarded-Proto: https
  2. Check reverse proxy configuration
  3. Verify force_ssl is not duplicated

Issue: Mixed content warnings
Fix:
  1. Verify APP_HOST is set
  2. Check asset URLs use HTTPS
  3. Update hardcoded HTTP URLs to HTTPS

Issue: Wildcard rejected
Fix:
  1. List each subdomain explicitly
  2. Example: www.example.com,api.example.com
  3. Do NOT use *.example.com

Issue: Health check fails with valid host
Fix:
  1. Verify APP_HOST matches request Host header
  2. Check application logs for errors
  3. Test with: curl -H "Host: ..." /health
