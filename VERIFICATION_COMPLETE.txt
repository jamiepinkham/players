🏥 HEALTH CHECK ENDPOINTS
=================================================================

1. GET /health or /healthz
   Purpose: Basic liveness check
   Response: 200 OK with status JSON
   Database: NO check
   Use: Liveness probes, load balancers

2. GET /health/ready
   Purpose: Readiness check with database
   Response: 200 OK or 503 Service Unavailable
   Database: YES check
   Use: Readiness probes, pre-deployment

3. GET /health/live
   Purpose: Liveness check (alias)
   Response: 200 OK with status JSON
   Database: NO check
   Use: Kubernetes liveness probes

🐳 DOCKER HEALTHCHECK
=================================================================

Added to Dockerfile.web.prod:

HEALTHCHECK --interval=30s --timeout=3s --start-period=60s --retries=3 \
  CMD curl -f http://localhost:3000/health || exit 1

Configuration:
- Interval: Check every 30 seconds
- Timeout: 3 seconds per check
- Start Period: Wait 60 seconds before first check
- Retries: Mark unhealthy after 3 failures
- Command: curl -f http://localhost:3000/health

Benefits:
✓ Docker knows when container is healthy
✓ Can restart unhealthy containers automatically
✓ Load balancers can detect unhealthy instances
✓ Orchestrators can make better scheduling decisions

🛠️ TROUBLESHOOTING
=================================================================

Issue: Health check returns 404
Fix:
  1. Check routes: rails routes | grep health
  2. Restart application
  3. Check logs for errors

Issue: Health check times out
Fix:
  1. Check container is running: docker ps
  2. Check port mapping: docker port <container>
  3. Check logs: docker logs <container>
  4. Increase wait time in verification script

Issue: /health/ready returns 503
Fix:
  1. Check database is running
  2. Verify DATABASE_HOST is correct
  3. Test database connection
  4. Check database logs

Issue: CI verification fails
Fix:
  1. Run local verification: ./scripts/verify_production_image.sh
  2. Check GitHub Actions logs
  3. Verify Dockerfile.web.prod syntax
  4. Check environment variables
